# FrostBite - Premium Ice Cream Experience

A high-end, "Apple-style" liquid glass web experience for a premium ice cream brand. Built with Next.js 15, Tailwind CSS v4, and Framer Motion.

## Features

- **Liquid Glass Design**: Advanced glassmorphism with fluid, physics-based animations.
- **Flavor Lab**: Interactive 3D-style "Build Your Scoop" experience.
- **Liquid Scroll**: Smooth, parallax scrolling effects.
- **Premium Assets**: High-quality, AI-generated imagery.
- **Functional Cart**: Full shopping cart state management.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Getting Started

1.  Install dependencies:
    ```bash
    npm install
    ```

2.  Run the development server:
    ```bash
    npm run dev
    ```

3.  Open [http://localhost:3000](http://localhost:3000) with your browser.

## Deployment

This project is optimized for deployment on Vercel.

```bash
npm run build
```
